# Dataset

The project uses the UCI **SMS Spam Collection** dataset.

Download/reference:
https://archive.ics.uci.edu/dataset/228/sms+spam+collection

The dataset contains 5,574 SMS messages labelled as `ham` or `spam`.

The training script retrieves the dataset using the `ucimlrepo` Python package, so the raw dataset does not need to be committed to GitHub.
